# Smart Health Mate — Setup Checklist

- [ ] Install Node.js
- [ ] Install/start MySQL
- [ ] Open project in VS Code
- [ ] Run `npm install`
- [ ] Run `database/schema.sql` in MySQL Workbench
- [ ] Create `.env` from `.env.example`
- [ ] Put your MySQL password in `.env`
- [ ] Run `npm start`
- [ ] Open http://localhost:3001
- [ ] Add a health record
- [ ] Verify BMI/BP/heart rate dashboard
- [ ] Add a second record
- [ ] Delete a record
- [ ] Take screenshots
- [ ] Push to GitHub
